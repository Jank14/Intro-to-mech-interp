Hooks — read anything, edit anything

A hook is a checkpoint on the forward pass. Your function is handed the activation as it passes. Return nothing → you only recorded. Return a tensor → you edited the model’s computation. Each section: ① Intuition first, then ② Code. Axis labels like B5 mean token B at position 5.

Hooks only affect what runs after them: zeroing layer 1 can never change layer 0’s pattern. A zeroed head is also indistinguishable, downstream, from a head that “found nothing” — which is why mean-ablation (replace with the average activation) is often the fairer test.
